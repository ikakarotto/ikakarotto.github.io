01 · Slash Commands（斜杠命令）

Slash command 是你在 Claude 交互式会话中用来控制行为的快捷方式，主要分为内置命令、Skills 和插件命令。

常用内置命令速查

命令作用
/help显示帮助信息
/clear清空对话历史
/compact压缩对话，可附带聚焦指令
/config打开设置
/cost查看 token 使用统计
/diff查看未提交更改的交互式 diff
/doctor检查安装健康状态
/export将当前对话导出为文件
/init初始化 CLAUDE.md
/mcp管理 MCP servers
/model选择模型
/plan进入规划模式
/rewind回退到 checkpoint
/sandbox切换 sandbox 模式
/status显示会话状态

提示：在 Claude Code 中输入 / 即可查看所有命令，也可以输入 / 后继续键入字母进行筛选。

02 · Memory（记忆系统）

Memory 让 Claude Code 在不同会话之间保留上下文。你可以把团队规范、项目规则、个人偏好写进 CLAUDE.md。

Memory 层级

层级作用范围典型内容
受管策略组织级合规、安全、统一流程
项目记忆单个项目架构、编码标准、工作流
目录记忆子目录模块约束、局部规范
用户记忆单个用户个人偏好、默认设置
# 快速上手：初始化 Memory
/init

# 这个项目始终使用 TypeScript 严格模式
# 优先使用 async/await，而不是 promise 链
# 每次提交前都运行 npm test

# 使用 /memory 打开记忆编辑器
/memory

03 · Skills（技能）

Skills 是可以复用、可自动触发的能力包。一个 skill 通常包含 SKILL.md、参考文件、脚本和模板。Claude 在合适的场景下会自动加载它。

三层加载机制（渐进式披露）

  1. 只看描述：先判断这个 skill 是否相关
  2. 加载 SKILL.md：读取核心说明
  3. 按需加载支持文件：脚本、模板、参考资料

创建自定义 Skill

my-skill/
└── SKILL.md
---
name: my-skill
description: 这个 skill 的用途，以及什么时候触发
---
# Your Skill Name

## Instructions

## Examples

最佳实践：描述要具体、保持聚焦、包含触发词、SKILL.md 控制在 500 行以内。

04 · Subagents（子代理）

Subagents 是专门处理某类任务的独立 AI 助手。它们拥有隔离的上下文、自己的提示词和工具权限，适合把复杂工作拆分给不同角色。

配置示例

---
name: code-reviewer
description: 审查代码质量和安全问题
tools: Read, Grep, Bash
---
# Code Reviewer

内置 Subagents：通用助手、Planning agent、Explore agent、Bash agent 等。

管理命令：/agents 列出可用 agents；claude agents 在 CLI 中查看。

05 · MCP（Model Context Protocol）

MCP 是 Claude Code 访问外部工具、服务和 API 的标准协议。你可以把 GitHub、数据库、文件系统等都接到 Claude 里。

常见 MCP Servers

Server说明安装
GitHubPR 管理、issues、代码claude mcp add github -- npx -y @modelcontextprotocol/server-github
DatabaseSQL 查询、数据访问claude mcp add db -- npx -y @modelcontextprotocol/server-postgres
Filesystem高级文件操作claude mcp add fs -- npx -y @modelcontextprotocol/server-filesystem
# 快速安装 GitHub MCP
export GITHUB_TOKEN="your_token" && claude mcp add github -- npx -y @modelcontextprotocol/server-github

06 · Hooks（事件钩子）

Hooks 是在 Claude Code 事件发生时自动执行的 shell 命令，用来做格式化、校验、通知、审计等自动化工作。

Hook 事件类型

  • Tool Hooks：PreToolUse、PostToolUse、PostToolUseFailure、PermissionRequest
  • Session Hooks：SessionStart、SessionEnd、Stop、StopFailure、SubagentStart、SubagentStop
  • Task Hooks：UserPromptSubmit、TaskCompleted、TaskCreated、TeammateIdle
  • Lifecycle Hooks：ConfigChange、CwdChanged、FileChanged、PreCompact、PostCompact 等
# 安装 hooks
mkdir -p ~/.claude/hooks
cp 06-hooks/*.sh ~/.claude/hooks/
chmod +x ~/.claude/hooks/*.sh

# 在 ~/.claude/settings.json 中配置：
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Write",
      "hooks": ["~/.claude/hooks/format-code.sh"]
    }]
  }
}

08 · Checkpoints & Rewind（检查点与回退）

Checkpoints 可以让你保存对话状态，并在 Claude Code 会话中回退到之前的时间点。无论你是在探索不同方案、修复错误，还是比较多个实现路径，这个能力都非常有用。

核心概念

概念说明
Checkpoint保存消息、文件和上下文的对话快照
Rewind回到之前的 checkpoint，并丢弃之后的更改
Branch Point从同一个 checkpoint 出发，探索多个方案

使用方法

  • 快捷键：按两次 Esc（Esc + Esc）打开 checkpoint 界面
  • 命令：/rewind 或 /checkpoint

Rewind 选项

  1. 恢复代码和对话
  2. 恢复对话（只回退消息）
  3. 恢复代码（只回退文件修改）
  4. 从这里开始总结
  5. 算了（取消）
💡 自动 Checkpoints：每次用户输入都会自动创建 checkpoint，跨会话保留，30 天后自动清理。

09 · 高级功能

Claude Code 的高级功能把基础能力扩展到了规划、推理、自动化和控制层面。

核心高级功能

  • Planning Mode：先写详细实现计划，再开始编码（/plan）
  • Extended Thinking：对复杂问题进行更深入的推理（Alt+T / Option+T 切换）
  • Background Tasks：长时间任务不阻塞对话
  • Permission Modes：default、acceptEdits、plan、auto、dontAsk、bypassPermissions
  • Print Mode：非交互式运行，适合自动化和 CI/CD（claude -p）
  • Session Management：/resume、/rename、/fork 等
  • Voice Dictation：按住说话，支持 20 种语言的语音识别
  • Agent Teams：多个 agent 协同处理复杂任务
  • Auto Mode：由后台安全分类器在每一步执行前进行审查

10 · CLI 参考

Claude Code 的 CLI（命令行接口）是与 Claude Code 交互的主要方式。

核心命令

命令说明示例
claude启动交互式 REPLclaude
claude "query"带初始提示启动 REPLclaude "解释这个项目"
claude -p "query"打印模式，查询后退出claude -p "解释这个函数"
cat file | claude -p处理管道传入的内容cat logs.txt | claude -p "解释这些日志"
claude -c继续最近一次会话claude -c
claude -r通过 ID 或名称恢复会话claude -r "auth-refactor"
claude update更新到最新版本claude update
claude mcp配置 MCP serversclaude mcp add github -- ...

核心标志

参数说明
-p, --print不进入交互式模式，直接输出结果
-c, --continue加载最近一次会话
-r, --resume按 ID 或名称恢复指定会话
-v, --version输出版本号
-w, --worktree在隔离的 git worktree 中启动
-n, --name设置会话显示名称
